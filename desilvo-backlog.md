# Бэклог аудита desilvo.by (образец: redsale.by)

desilvo.by — сервис подбора мастеров: клиент создаёт задание, мастера откликаются. Не доска объявлений.

Правило: за один запуск — один модуль. Статусы: `открыт` → `в работе` → `ждёт подтверждения` → `закрыт`.
Изменения БД и живого сайта — только после подтверждения владельца.
Репозиторий публичный: никаких имён, телефонов, e-mail, ссылок на профили людей и паролей.
