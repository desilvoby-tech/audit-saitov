## Что есть сейчас на desilvo.by

- Поиск только в первом экране главной; чипы-подсказки (6 шт.) ведут сразу в форму задания.
- Подсказки работают: до 10 вариантов, клавиатура (↑/↓/Enter/Esc), подсветка совпадения, категория справа. Задержка 120 мс, без запросов к серверу.
- Выбор подсказки или «Найти» → `app.html#new-<текст>`: открывается мастер создания задания. Для точного названия услуги (пример: «Сантехник») подставляются вопросы по услуге («Что именно нужно?» с вариантами) — это хорошо.
- Город в поиске не участвует (город выбирается позже, в форме). У образца тоже — паритет, не ошибка.

## Найденные проблемы

1. **Нет нормализации «ё/е».** «теплый пол», «счетчик», «шпаклевка» не находят «Тёплый пол», «счётчик», «Шпаклёвка». Пользователи почти всегда пишут «е».
2. **Нет учёта словоформ.** «смеситель» не находит «Установка смесителя», «плитк» — «Плиточник». Поиск — точная подстрока, морфологии нет.
3. **Ложные совпадения внутри слова.** «кран» → ремонт телефонов/ноутбуков (из синонима «замена экрана»). Поиск ищет подстроку в любом месте слова, а не с начала слова.
4. **Нет устойчивости к опечаткам и неправильной раскладке** («сантехникк», «cfynt[»).
5. **Пустой результат без подсказки, что делать.** При 0 совпадений выпадающий список просто не появляется. Нет варианта «Создать задание «…»» и ссылки на каталог.
6. **Свободный текст минует категорию.** «потекла труба» → форма с услугой «потекла труба»: шаг уточняющих вопросов пропускается, категория не определяется. Вероятно, такое задание хуже доходит до нужных мастеров (рассылка мастерам идёт по услуге/городу — *проверить на стороне владельца*, как такое задание маршрутизируется).
7. **Нет поиска в каталоге /uslugi/** (231 услуга, 18 разделов) и на страницах услуг — найти услугу можно только вернувшись на главную или листая.
8. **Подсказка ведёт только в форму**, а не на страницу услуги /uslugi/{slug} (цены, мастера, FAQ). У образца так же — паритет, но для desilvo можно дать вторичную ссылку «Цены и мастера».
9. **Нет статистики «пустых» запросов.** Без неё синонимы пополнять вслепую. У образца в ответе API есть `searchId` — запросы явно логируются.
10. **(мелочь)** В разметке поле уже приходит с `data-sg="1"`, а `attachSuggest` выходит при наличии этого атрибута. Сейчас подсказки фактически работают (проверено), но код хрупкий: при изменении порядка инициализации подсказки молча пропадут. *Проверить в исходниках*, откуда берётся атрибут в HTML.

## Предложения по исправлению (не применены)

**П1. Заменить `desilvoSuggest` на поиск по словам с нормализацией, основой слова и опечатками (2 прохода).** Черновик проверен в консоли браузера на реальном справочнике `DSVC` (без изменения сайта): «теплый пол», «смеситель», «смесителя», «плитк», «сантехникк», «cfynt[», «ремонт стиралки» дают правильную услугу первой, «кран» больше не даёт ремонт телефонов.

```js
const norm=s=>String(s).toLowerCase().replace(/ё/g,'е').replace(/[^a-zа-я0-9]+/g,' ').trim();
const EN="qwertyuiop[]asdfghjkl;'zxcvbnm,.`", RU='йцукенгшщзхъфывапролджэячсмитьбюё';
const fixLayout=s=>/^[a-z\[\];',.`\s]+$/.test(s)?s.replace(/./g,c=>{const i=EN.indexOf(c);return i<0?c:RU[i]}):s;
const stem=w=>w.length>=5?w.slice(0,Math.max(4,w.length-2)):w;          // грубая основа: смеситель→смесите, плитк→плит
const lev1=(a,b)=>{if(Math.abs(a.length-b.length)>1)return false;let i=0,j=0,e=0;
  while(i<a.length&&j<b.length){if(a[i]===b[j]){i++;j++;continue}if(++e>1)return false;
    if(a.length>b.length)i++;else if(b.length>a.length)j++;else{i++;j++}}
  return e+(a.length-i)+(b.length-j)<=1};
const IDX=DSVC.map(x=>({x,name:norm(x.t).split(' '),syn:norm(x.v.join(' ')+' '+x.c).split(' ')}));
function hit(q,words,fuzzy){const s=stem(q);let best=0;
  for(const w of words){ if(w.startsWith(q))return 3; if(w.startsWith(s))best=Math.max(best,2);
    else if(fuzzy&&q.length>=5&&lev1(q,w.slice(0,q.length)))best=Math.max(best,1);} return best;}
function searchPass(qs,fuzzy){const out=[];
  for(const it of IDX){let sc=0,ok=true;
    for(const t of qs){const n=hit(t,it.name,fuzzy),v=hit(t,it.syn,fuzzy); if(!n&&!v){ok=false;break} sc+=n*3+v;}
    if(ok)out.push({it,sc});}
  return out.sort((a,b)=>b.sc-a.sc||a.it.x.t.length-b.it.x.t.length);}
function desilvoSuggest(raw,hl){
  const qs=norm(fixLayout(raw.toLowerCase().trim())).split(' ').filter(Boolean); if(!qs.length)return [];
  let res=searchPass(qs,false); if(!res.length)res=searchPass(qs,true);        // опечатки — только если точных нет
  const items=res.slice(0,8).map(({it})=>({svc:it.x.t,
    html:'<span>'+esc(it.x.t)+'</span><span class="sg-c">'+esc(it.x.c)+'</span>'}));
  items.push({svc:raw.trim(),free:true,html:'<span>Создать задание «'+esc(raw.trim())+'»</span><span class="sg-c">своими словами</span>'});
  return items;
}
```
Примечание: второй проход (опечатки) включается только при пустом первом — иначе «уборка» цепляет «Сборка мебели».
