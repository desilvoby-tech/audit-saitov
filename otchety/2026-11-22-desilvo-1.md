# Аудит desilvo.by — модуль 1 «Главная и категории»

Дата: 2026-11-22 · Образец: redsale.by · Запуск по расписанию

## Как проверялось

- Браузер в этом запуске был недоступен (прямой выход в сеть из среды закрыт прокси), поэтому страницы читались через web fetch. **JavaScript не выполнялся** — блоки, которые подгружаются скриптом, видны только как заглушки. Пункты, помеченные «проверить в браузере», требуют ручной проверки.
- Открыты страницы: desilvo.by/ , desilvo.by/uslugi/ , desilvo.by/uslugi/santehnik-minsk , redsale.by/ . Все отдали HTTP 200.
- Важное уточнение к бэклогу: оба сайта — не доски объявлений, а сервисы подбора исполнителей (задание/заявка → отклики мастеров). Поэтому «счётчики объявлений» сравнивались как счётчики мастеров/заданий/отзывов.

## Найденные проблемы

1. **Блоки-заглушки на главной.** «Что заказывают прямо сейчас» («Загрузка заданий…») и «Исполнители» («Загрузка…») в HTML пустые; на /uslugi/santehnik-minsk — «Загрузка мастеров…». Поисковики и пользователи с медленным JS видят пустоту. *Проверить в браузере*, приходят ли данные вообще и что показывается, если заданий/мастеров нет.
2. **Пустой блок «Услуги по всей Беларуси»** на главной: заголовок и подсказка есть, карточек нет. *Проверить в браузере* — если и после JS пусто, это ошибка.
3. **Странный символ валюты** в форме на главной: «Бюджет, ƃ». Вероятно, знак BYN из иконочного шрифта, который не подгрузился, либо битая кодировка. На других страницах не встречается.
4. **Битый якорь:** ссылка «Создать задание» в футере ведёт на #order, а такого id в HTML не найдено (форма, видимо, имеет другой id). *Проверить в браузере.*
5. **Нет группировки рубрик на главной.** 12 плоских услуг против 10 тематических групп у образца; 18 разделов каталога на главной не видны.
6. **Расхождение списка городов:** на главной 6 городов, на /uslugi/ и на страницах услуг — 7 (есть Бобруйск).
7. **Грамматика:** «231 услуг» в тексте и meta description /uslugi/ — нужно «231 услуга» (лучше склонять программно).
8. **noindex на городских страницах:** /uslugi/santehnik-minsk отдаёт `meta robots = noindex,follow`. Если это не намеренно (например, пока нет мастеров), страницы услуг по городам не попадут в поиск. Относится и к модулю 9 (SEO) — решение за владельцем.
9. **Нет социального доказательства** (рейтинг, число мастеров/выполненных заданий, отзывы) — у образца это центральный блок главной.

## Предложения по исправлению (не применены)

**П1. Серверный (или fallback) вывод блоков «Задания»/«Исполнители».** Минимум — понятное пустое состояние вместо вечной «Загрузки» и таймаут:

```js
// пример для блока заданий
const box = document.querySelector('#tasks-now');
const t = setTimeout(() => { box.innerHTML = emptyState(); }, 8000);
fetch('/api/tasks?limit=6').then(r => r.ok ? r.json() : Promise.reject(r.status))
  .then(list => { clearTimeout(t); box.innerHTML = list.length ? list.map(card).join('') : emptyState(); })
  .catch(() => { clearTimeout(t); box.innerHTML = emptyState(); });
function emptyState(){ return '<p>Пока нет новых заданий. <a href="/app.html#new">Создайте первое</a></p>'; }
```
(имена селектора и API — условные, подставить фактические.)
Лучше — отдавать первые 6 карточек сразу в HTML при генерации страницы.

**П2. Блок «Услуги по всей Беларуси»** — наполнить группами из каталога (как у образца): 8–10 крупных разделов из /uslugi/, в каждом 5–6 ссылок + «Все услуги». Пример разметки:

```html
<section class="cats">
  <div class="cat"><h3><a href="/uslugi/#remont">Ремонт и строительство</a></h3>
    <ul><li><a href="/uslugi/santehnik">Сантехник</a></li><li><a href="/uslugi/elektrik">Электрик</a></li> …</ul></div>
  …
  <a class="all" href="/uslugi/">Все услуги — 231</a>
</section>
```
(слаги кроме santehnik — проверить по каталогу.)

**П3. Валюта:** заменить «ƃ» на текст «BYN» или «руб.» (`Бюджет, BYN`), не зависеть от иконочного шрифта.

**П4. Якорь:** в футере заменить `#order` на фактический id формы на главной (или добавить `id="order"` секции с формой).

**П5. Города:** выровнять список на главной с каталогом (добавить Бобруйск) — один общий источник списка городов.

**П6. Склонение:**

```js
function plural(n, f){ const a=n%100, b=n%10; return f[(a>10&&a<20)?2:b===1?0:(b>1&&b<5)?1:2]; }
// `${n} ${plural(n,['услуга','услуги','услуг'])} в ${m} ${plural(m,['разделе','разделах','разделах'])}`
```

**П7. Соц. доказательство:** когда появятся реальные данные — строка под первым экраном: число мастеров, выполненных заданий, средняя оценка. Только фактические цифры из БД, без выдуманных отзывов.

**П8. noindex:** решить политику — например, снимать noindex с городской страницы, когда в ней ≥ N мастеров (передать в модуль 9).
