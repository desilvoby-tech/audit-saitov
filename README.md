# audit-saitov

Аудит сайтов abisto.by (образец kufar.by) и desilvo.by (образец redsale.by).

- `abisto-backlog.md`, `desilvo-backlog.md` — модули и их статусы.
- `otchety/ГГГГ-ММ-ДД-<сайт>-<модуль>.md` — отчёт одного запуска.

Репозиторий **публичный**. Персональные данные (контакты, заявки, согласия) хранятся только
в закрытом репозитории `kontakty-obshchie` и сюда не попадают.
